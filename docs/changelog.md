# 更新日志

## v1.0.0 - 2026-08-25

开放 API 首个版本，基础地址 `https://api.lrcshare.com`。

- 四维搜索：单曲 / 专辑 / 艺术家 / 歌词内容
- 歌曲元数据全量开放：歌名、别名、歌手、专辑、时长、曲目号、碟号、流派、词曲编署名、封面、视频链接、贡献者
- 歌词接口：LRC（末尾自动附来源署名行）+ 纯文本对照
- 专辑详情（含完整曲目表）、艺术家详情与作品列表（带角色标注）
- 署名链路：song 对象 `comment` 字段与 LRC 末尾统一为 `本歌词来自于:贡献者名@lrcshare.com`
- 匿名调用、跨域支持、边缘缓存（详情 1h / 列表 10min）
