# 使用要求

LrcShare API 免费开放，但需要申请 **API Key** 才能使用。服务能力有限（Cloudflare Workers 免费额度 10 万请求/天），请保持克制，让免费服务能长久供所有人使用。

## 如何获取 API Key

请发邮件到 **lrcshare@qq.com** 申请，说明你的使用场景，并附上项目地址或软件官网，站长审核后发放。Key 格式为 `ls_` 前缀 + 32 位字符。

Key 发放后请妥善保管，若被滥用站长有权随时封禁。

## Key 按程序签发，不按用户签发

如果你开发了插件或软件并打算公开分发，请**由开发者本人申请一个 Key 内置到程序里**，不要在程序的使用说明里写「请自行向站长申请 API Key」，让终端用户挨个来申请。

- **一个程序一个 Key**：程序内所有用户共用同一个 Key，而不是每个用户各申请一个
- 站长一个人处理不了大量个人申请，这也是这个免费 API 还能维持的前提
- 面向公众分发的客户端，内置 Key 必然会被看到，这属于预期情况，不需要私有仓库；真出滥用，站长可按 Key + IP 封禁
- 自己写脚本、个人自用的小工具同样按这个原则：一个程序一个 Key
- **不支持**「开发者开发程序、终端用户自行申请 Key」这种把申请负担转嫁给用户的分发方式

## API Key（X-API-Key）

所有请求必须携带 `X-API-Key` 头：

```
X-API-Key: ls_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

- 未携带 Key，或 Key 不在 WAF 白名单内 → 在 Cloudflare 边缘直接拦截，返回 HTTP **403** + HTML 拦截页（不是 JSON 响应）
- Key 已在白名单内、但被后台封禁 → HTTP **403**（JSON，`message: invalid or banned api key`）
- 滥用 API Key 会被封禁，封禁后立即失效

## 浏览器调用

浏览器跨域调用（`fetch`）会自动先发 `OPTIONS` 预检。预检请求按 CORS 规范**不携带** `X-API-Key`，因此服务端对 `OPTIONS` 不做 Key 校验，直接放行并返回 CORS 头。预检结果缓存 24 小时（`Access-Control-Max-Age`），同一页面重复调用不会反复触发预检。

注意：在浏览器地址栏直接打开接口地址**无法携带** `X-API-Key`，会被边缘拦截。调试请使用 curl、Apifox / Postman，或在浏览器控制台用 `fetch` 发起跨域请求。

## Catalog-First（必须先拉目录）

除 `/v1/catalog` 本身外，访问其他端点前必须先调用 `GET /v1/catalog`，从响应中获取 `session_token`，并在后续请求中携带 `X-LrcShare-Session` 头：

```
X-LrcShare-Session: <catalog 返回的 session_token>
```

`session_token` 有效期 24 小时，过期后需重新拉 catalog。未携带或已过期 → HTTP **419**。

官方 Lyrico 插件已内置此逻辑（自动获取并缓存 session_token）。

## 速率限制

单个 IP 超过 **300 次 / 10 秒** 会被临时阻止（HTTP 429），约 10 秒后自动解封。

- 正常手动使用远达不到阈值
- 批量工具请控制并发、串行处理，别开并发轰炸
- 触发限流时请退避重试，不要立即重试轰炸（否则会持续被拦）

## 请求节流

批量操作（如扫描整个音乐库）建议：

- **顺序请求**：等上一个请求完成再发下一个
- **加延迟**：请求间间隔 200 ~ 500ms

## 缓存

相同 URL 的响应会在 Cloudflare 边缘缓存：

| 类型 | 缓存时长 |
| --- | --- |
| 列表 / 搜索 | 10 分钟 |
| 详情 | 1 小时 |

- **别在 URL 里加时间戳、随机数等噪声参数**，否则命中不了边缘缓存，重复查询都打到源站
- 全量同步请用分页 `limit=100` 逐页拉取，别开并发轰炸

## 目录快照（批量工具必读）

全量同步或批量打标前，先拉一次 [`GET /v1/catalog`](/api/catalog) 拿全库可搜索文本快照（建议本地缓存 24 小时），在本地过滤命中候选再发搜索请求——一次目录请求可替你省掉成千上万次无效搜索。官方 Lyrico 插件已内置此逻辑。

## 空结果是正常业务结果

LrcShare 是小众人工整理曲库，命中是概率事件。`items: []` 不是错误，请做好兜底逻辑，不要重试轰炸。

## 错误码

鉴权相关：403（未携带 Key 或不在白名单，边缘拦截返回 HTML）/ 403（白名单内但已封禁，返回 JSON）/ 419（Session 过期）。完整错误码对照表见[错误码](/api/errors)。
