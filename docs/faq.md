# FAQ

## 需要注册或 API Key 吗？

需要。所有接口都要求携带 `X-API-Key`，Key 免费申请（见[快速开始](/guide/quickstart#获取-api-key)）。官方 Lyrico 插件已内置 Key，安装后无需手动配置；自己写脚本或客户端需要单独申请。

## 有频率限制吗？

- **鉴权拦截**：未携带 `X-API-Key`、或 Key 不在白名单内，请求会被 Cloudflare 边缘直接拦截（HTTP 403，返回 HTML 拦截页而非 JSON）
- **限流**：单个 IP 超过 300 次 / 10 秒会被边缘拦截，返回 HTTP 429，约 10 秒后自动恢复
- 列表与搜索结果缓存 10 分钟，详情与歌词缓存 1 小时，正常使用（逐首查歌词、批量打标）远达不到限制阈值
- 需要全量同步时请用分页 `limit=100` 逐页拉取，别开并发轰炸

## 数据多久更新一次？

与主站同一份数据库，主站每 6 小时自动构建一次；新审核通过的歌曲最迟当天可查（接口读库，实际比主站页面更快生效，边缘缓存最长延迟 1 小时）。

## 为什么搜索结果里没有歌词和词曲编？

两段式设计：搜索/列表只返回轻量摘要（歌名/歌手/专辑/年份/风格/封面），适合渲染选择列表；用户确认目标后再用 `id` 调 `/v1/song/:id`，一次拿到歌词、词曲编、comment 等全部数据。列表响应保持小体积，选择体验更快。

## 隐藏歌曲能查到吗？

能。主站上需要口令解锁的隐藏歌曲，API 同样返回其元数据与歌词——歌曲的词曲信息与歌词一并提供，方便打标。但请尊重来源，署名字符串（`comment` / LRC 末尾行）请随歌词一并保留。

## 可以商用吗？

歌词版权归各自权利人，LrcShare 只做整理与分享。API 供个人学习、本地音乐库整理、播放器歌词展示等非商业用途使用；商业使用请先联系站长（见主站关于页）。

## 报错 `404 song not found` 但主站能打开？

检查 ID 是否正确：API 的歌曲 ID 与主站歌曲页 URL 中的 ID 一致（如 `/song/s_purplesoul_013`）。另外歌曲若处于待审核/下架状态（非 `published`），API 不会返回。

## 返回 403，内容是一个 HTML 页面而不是 JSON？

这是 Cloudflare 边缘拦截。常见原因是未携带 `X-API-Key`，或该 Key 还没有加入白名单——刚签发、尚未生效的 Key 也是这个结果。确认 Key 与签发时一致后，联系站长核对白名单状态。

## 支持 HTTPS / HTTP？

仅 HTTPS（`https://api.lrcshare.com`），HTTP 请求会被 Cloudflare 重定向。

## 我想接入我的播放器/脚本，支持跨域吗？

支持。所有响应带 `Access-Control-Allow-Origin: *`，浏览器环境直接 `fetch`，无需代理。
